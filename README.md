# Vendor Risk Assessment & Third-Party Risk Management (TPRM)

## Overview
This project demonstrates a Third-Party Risk Management (TPRM) assessment conducted for a cloud storage service provider. The assessment was performed using ISO 27001 security control principles to identify, evaluate, and mitigate vendor-related cybersecurity risks.

## Project Scope
- Access Control Review
- Encryption Assessment
- Incident Response Evaluation
- Logging & Monitoring Review
- Compliance Verification

## Deliverables
- Project Charter
- Vendor Security Questionnaire
- Risk Register
- Risk Matrix
- Risk Treatment Plan

## Key Risk Findings
- Lack of Multi-Factor Authentication (MFA)
- Absence of ISO 27001 Certification
- Weak Incident Response Process
- Insufficient Logging and Monitoring

## Risk Treatment Actions
- Implement MFA
- Improve Incident Response Testing
- Enable Centralized Logging
- Initiate ISO 27001 Certification Program
